# Image Quality Assessment for AI-Generated Satellite Imagery

Final-year CS project (CS3IP, University of Reading) combined with an AI research placement (Crocus / AI-INTERVENE), supervised by Dr Hong Wei.

**Aim:** build a benchmarking pipeline that generates synthetic Sentinel-2 sargassum imagery with a diffusion model and evaluates it against real data, using metrics that reveal whether generated images are scientifically usable, beyond PSNR/SSIM.

**Status:** Phase 1 (literature review) and Phase 2 (dataset/model selection, environment setup).

## Repository structure

```
docs/     project direction and research summary
logs/     weekly logs: fyp_log.md (CS FYP) and placement_log.md (placement)
data/     README with dataset links/DOIs + small sample images only
```

Raw datasets and model weights are **not** stored here (see `.gitignore`).
